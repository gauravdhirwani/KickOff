Tournament Manager Backend - Schema & API Design

DATABASE SCHEMA

1.  Tournament

-   id (PK)
-   name
-   start_date
-   end_date
-   status (UPCOMING, ONGOING, COMPLETED)

2.  Team

-   id (PK)
-   name
-   tournament_id (FK -> Tournament.id)

3.  User

-   id (PK)
-   name
-   email (UNIQUE)
-   password (hashed)
-   role (ADMIN, PLAYER)
-   jersey_number
-   position (GK, DEFENDER, MIDFIELDER, FORWARD)
-   team_id (FK -> Team.id, NULL for ADMIN)

Rules: - ADMIN -> team_id = NULL - PLAYER -> team_id NOT NULL

4.  Fixture

-   id (PK)
-   tournament_id (FK)
-   home_team_id (FK)
-   away_team_id (FK)
-   match_date
-   home_score
-   away_score
-   status (SCHEDULED, COMPLETED)

Winner is derived from scores.

5.  Goal

-   id (PK)
-   fixture_id (FK)
-   scorer_id (FK -> User.id)
-   assist_player_id (FK -> User.id, nullable)
-   minute

RELATIONSHIPS

Tournament ├── Teams └── Fixtures

Team └── Users (Players)

Fixture └── Goals
